01 / Web application

Healthy Life
Clinic

A PHP and MySQL coursework application for patients and clinic administrators.

PHPMySQLHTML / CSS

A role-based clinic application covering patient registration, appointments, medical records and administration. I developed and tested workflows locally, then uploaded the application to a web host and checked it on an Android phone.

What I built

  • Patient registration and login, with patient and administrator roles.
  • Appointment booking, editing and deletion, with appointment-time validation.
  • Patient administration using create, read, update and delete operations.
  • Hashed passwords and form validation.

What this demonstrates

Connecting forms to a relational database, handling user permissions, validating input and troubleshooting an application across local and hosted environments.

Problem solving in practice

During setup, I resolved a MySQL access error by correcting the database configuration. I also adjusted the appointment date and time layout when it caused unwanted scrolling, then retested the page. Hosting checks included resolving an initial 404 and checking the site on mobile.

This is an educational project using clinic workflows, rather than a production healthcare system.

02 / Responsive website

Snazzy Paws

A seven-page dog grooming website, developed through successive web development assessments.

HTMLCSSBootstrap 5.3.3

I migrated the original five-page website to Bootstrap, retaining its colours and existing content while improving responsive layouts. I added privacy and staff roster pages.

What I built

  • Responsive navigation, home-page columns and tables.
  • Consistent form controls, buttons and custom CSS.
  • Page descriptions and viewport metadata on all seven pages.
  • A privacy page explaining the static forms, plus a sample staff roster.

What this demonstrates

Improving an existing website, working with a CSS framework, maintaining visual consistency and checking layouts at desktop and mobile sizes.

A hosting lesson

I prepared an Apache Basic authentication configuration for the staff area. It needs a real server path, a password file outside the public directory and appropriate Apache settings. GitHub Pages does not enforce Apache .htaccess files, so static hosting alone does not protect that page.
